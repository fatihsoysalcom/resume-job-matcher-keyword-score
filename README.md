# Resume Job Matcher Keyword Score

This example demonstrates how to match a resume against a job description using keyword extraction and scoring. It identifies and highlights relevant terms from the job posting found within the resume, providing a simple relevance score. This helps candidates understand how well their resume aligns with a specific job and where they might need to tailor their application.

## Language

`python`

## How to Run

Save the code as `resume_matcher.py`.
Run from your terminal: `python resume_matcher.py`
